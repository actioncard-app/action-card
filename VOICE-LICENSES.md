# Natural voice: components and licenses

LetterScan's natural voice runs entirely on the phone. Letter text is never sent anywhere. The only network
use is the optional one-time download of a voice pack the user starts in Settings; every file is checked against
the SHA-256 compiled into the app (`src/lib/tts/voice-packs.json`) before it is used, and then it works offline.
No eSpeak-ng, piper-phonemize or other GPL code is built, linked or bundled.

## Languages without a natural voice (the iPhone's own voice is used)

- Italian: a commercial-OK Coqui model exists (Apache-2.0, mai_male/mai_female) but there is no ONNX export of it yet; not shipped.
- Ukrainian: excluded. The Coqui model is BSD-3, but M-AILABS says its Ukrainian audio was provided "for machine learning purposes only".
- Turkish, Arabic, Russian, Persian, Vietnamese, Chinese, Tagalog, Hindi, Urdu: no checked voice is both commercial-OK and usable without
  eSpeak-ng (Kokoro zh/hi need extra frontends; Meta MMS voices are CC-BY-NC and excluded).
- Kokoro's own es/fr/it/pt/hi/ja voices need an eSpeak-style phonemizer, so they are not used.
